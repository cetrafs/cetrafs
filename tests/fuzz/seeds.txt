# Fuzz seeds that produced a finding, replayed by every fuzz stage before
# its random run (tests/fuzz/seeds.sh). A failure is always meaningful:
# a seed that found something once is checked again on every run, not
# only when someone remembers it.
#
# One line per seed:
#   <fuzzer> <seed> <iters> <first found, UTC> <last failed, UTC> <note>
# <fuzzer> is the fuzz.py mode (fsck, fsck-fields, mount, mount-fields);
# <iters> reaches the finding, a little past its iteration. A replay that
# fails again rewrites <last failed> itself -- commit that change.
#
# A seed reproduces its exact sequence only while the golden image and
# fuzz.py's choices stay as they were; after they change it is still a
# fixed, cheap sequence that once mattered. Pruning: when the list grows
# too long, drop the lines whose <last failed> is oldest -- a seed that
# has not failed for months is the first to go.
